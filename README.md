# Neon God: -3

Dive into a frenetic, cyberpunk classic arcade-style space shooter where you pilot a radiant warframe through endless waves of mutated drones and cosmic anomalies; chain critical-strikes, trigger cinematic explosions, and evolve devastating armaments as you ascend the leaderboards — fast, flashy, and impossible to put down.

View your app in AI Studio: https://ai.studio/apps/drive/1k94ivjpSH54OmI485q3hZLzEIqGeTx-6

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
